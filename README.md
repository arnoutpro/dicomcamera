# dicomcamera

Android clinical camera: capture photos/videos as DICOM, bind via Modality Worklist or PACS query, store to any standards-compliant PACS, then purge local copies.

**Android only. PACS/EHR vendor independent. No durable on-device archive after successful send.**

Blank repo + product plan. Implementation has not started.
